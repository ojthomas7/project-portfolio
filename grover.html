Grover’s Algorithm

Suppose we want to search through a set of data to locate the position of a particular value. On a classical computer, if there are N values, it would require O(N) operations to find the index of the value we are searching for. Using a quantum algorithm known as Grover's algorithm, we can speed this up, requiring only O(sqrt(N)) operations.

This project implements Grover's algorithm with a circuit initialized with 3 qubits (specific to this example). It begins by using an oracle to produce a phase-flip if the target state is detected, marking our target state. The state then passes through a diffusion operator, which produces a phase inversion about the mean, amplifying the marked target state. Finally, we measure the states, finding our target state to be measured most often.
